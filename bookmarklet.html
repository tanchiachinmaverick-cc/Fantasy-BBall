Copy-table bookmark

This adds a button to your browser. Click it while you are on the Hashtag Basketball projections page and it copies the projections table to your clipboard, ready to paste into the draft app. It only reads the page you are looking at and sends nothing anywhere.

Step 1 – Show your bookmarks bar

Chrome / Edge: press Ctrl+Shift+B (Windows) or Cmd+Shift+B (Mac). Safari: View menu → Show Favorites Bar.

Step 2 – Drag this button up to the bookmarks bar

Copy HB table

If dragging does not work, use the manual method below.

Step 3 – Use it

  1. Go to the NBA projections page on hashtagbasketball.com and wait for the table to load.
  2. Click Copy HB table in your bookmarks bar. A message says how many players were copied.
  3. Open the draft app, click in the import box, paste (Ctrl+V / Cmd+V) and click Import.

Manual method (if dragging fails)

  1. Click the box below and press Ctrl+A then Ctrl+C to copy all the code.
  2. Right-click the bookmarks bar → Add page (or Add bookmark). Name it Copy HB table, paste the code into the URL field, and save.

If the site is paginated or filtered, the bookmark copies only the rows currently shown. If it says it cannot find the table, or the site blocks bookmarks, select and copy the table by hand as before.
